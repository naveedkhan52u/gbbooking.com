# GBbooking.com Assets

This folder stores shared website media. Keep uploaded files organised by purpose.

## Folders
- `brand/`: official logo files, favicon and brand variations.
- `images/banners/`: homepage and page banners.
- `images/services/`: accommodation, transport, tours, events and home-service images.
- `images/destinations/`: Gilgit-Baltistan destination and location photography.
- `images/blog/`: blog thumbnails and editorial images used on the website.
- `icons/`: custom SVG icons.

Prefer optimised WebP or AVIF for photographs. Keep transparent logos as SVG or PNG. Use descriptive, lowercase filenames, for example `hunza-valley-banner.webp`.

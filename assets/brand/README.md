# Brand assets

Upload the official GBbooking.com logo here.

Suggested filenames:
- `logo.svg` or `logo.png`: primary logo.
- `logo-white.svg` or `logo-white.png`: logo for dark backgrounds.
- `logo-mark.svg` or `logo-mark.png`: icon-only version.
- `favicon.svg` or `favicon.png`: browser tab icon.

When uploading the logo, tell us its exact filename so the website can be updated to use it.
